# 菜小智 VegiSmart｜比赛演示源码

> 让 AI 从看见食材走向会买、会搭、会做

这是“霍格沃茨”团队为 2026 中国高校计算机大赛人工智能创意赛准备的可演示源码。项目围绕线下生鲜采购中“不会挑、不会估价、不会搭、买回去不会做”的连续痛点，构建“识别—判断—搭配—购买—烹饪—记录”的决策闭环。

## 30 秒启动

1. 双击根目录的 `启动演示_Windows.bat`；或直接打开 `web-demo/index.html`。
2. 点击“拍照识菜”→“模拟拍摄并识别”。
3. 查看番茄识别、新鲜度、参考价格与购买量。
4. 点击“加入食材并智能搭配”→选择方案→勾选购物清单。
5. 点击“进入做菜模式”，查看定量步骤；右上角“✦”可体验 AI 问答。

网页演示不依赖网络、模型密钥或后端，适合评审现场稳定演示。

## 目录

- `web-demo/`：可直接运行的高完成度交互原型。
- `harmonyos/VegiSmart/`：ArkTS + ArkUI Stage 模型工程源码，可用 DevEco Studio 导入。
- `docs/`：技术说明、测试报告、评分点对照、演示指引和报名文档。

## HarmonyOS 构建

1. 在 DevEco Studio 中打开 `harmonyos/VegiSmart`。
2. 等待项目同步并配置本机 HarmonyOS SDK。
3. 选择模拟器或真机，完成签名配置后运行 `entry`。

仓库没有伪造已签名 HAP；最终 HAP 应由参赛团队在自己的 DevEco Studio 与签名环境中生成。工程已声明 Camera 与 Internet 权限，并提供可稳定演示的本地模拟分析服务。

## 核心技术路径

- Camera Kit：用户主动拍摄食材，保留显式授权和可撤销入口。
- 食材视觉识别：分类/检测食材类别，并提取可见新鲜度特征。
- 食品规则引擎：将视觉特征转为保存、安全、替代和购买建议。
- 大模型编排：结合人数、预算、口味、技能、健康目标与库存生成方案。
- Network Kit：真实落地时连接价格、营养与模型服务；离线演示使用确定性数据保证稳定。

## 重要边界

新鲜度和价格结果均为辅助参考，不替代现场感官判断、食品安全标准或商家标价。出现异味、渗液、霉变、包装胀气等情况时应停止食用。
